# Manual Collection Run Sheet / คู่มือเก็บข้อมูลด้วยมือ

เอกสารนี้คือขั้นตอนมาตรฐานสำหรับเก็บคำตอบจาก **Gemini (web), ChatGPT (web), Perplexity (web), Google AI Mode** ด้วยมือ
เพื่อให้ผู้เก็บ 2 คนได้ข้อมูลที่เทียบกันได้ ทุกครั้งที่เก็บให้ทำตามนี้ทุกข้อ ถ้าทำต่างไปให้จดไว้ใน `--note`

> **ทำไมต้องเก็บด้วยมือ:** ข้อกำหนดการใช้งาน (Terms of Service) ของ engine เหล่านี้ห้ามการเก็บข้อมูลอัตโนมัติ (scraping)
> ส่วนที่ยังรันอัตโนมัติมีแค่ **Gemini API** (`python -m aiso.collect --provider gemini --no-search`)
> ห้ามใช้สคริปต์, extension, หรือ bot ช่วยกด/คัดลอกบนหน้าเว็บของ engine เหล่านี้

---

## 1. Before you start / เตรียมก่อนเริ่ม

1. สร้าง checklist ของรอบนี้ แล้วพิมพ์หรือเปิดไว้ข้าง ๆ

   ```bash
   python -m aiso.runsheet --repeats 3 --out reports/runsheet     # -> reports/runsheet.md + .csv
   ```

   (ถ้าไม่มี `config.json` จะใช้ `config.example.json` แทน — **ตอนเก็บจริงต้องมี `config.json` ของโปรเจกต์**)
2. ตกลงกันว่าใครเก็บ engine ไหน รอบไหน (ดูข้อ 4) และใช้อักษรย่อเดิมตลอด เช่น `TN`, `PK`
3. เปิด terminal แล้วเริ่ม session ของ engine นั้น

   ```bash
   python -m aiso.manual --provider perplexity --repeat 0 --who TN \
       --note "Chrome 130 incognito, logged-out, Bangkok, home wifi"
   ```

   | option | ความหมาย |
   |---|---|
   | `--provider` | `gemini` / `chatgpt` / `perplexity` / `aimode` (บันทึกเป็น `<provider>_app`) |
   | `--repeat N` | เลขรอบตาม checklist (เริ่ม 0) |
   | `--rounds K` | เก็บ K รอบติดกัน (ไม่แนะนำ — ควรกระจายรอบข้ามวัน) |
   | `--queries 1,3,5-7` | เก็บเฉพาะบางข้อ (เลขตาม checklist เริ่มที่ 1) |
   | `--who` | อักษรย่อผู้เก็บ |
   | `--note` | สภาพแวดล้อม: เบราว์เซอร์, incognito, login หรือไม่, ที่อยู่/เครือข่าย, model ที่หน้าเว็บแสดง |
   | `--redo` | เก็บซ้ำ query+repeat ที่มีในไฟล์แล้ว (ปกติโปรแกรมจะข้ามให้ เพื่อให้หยุดแล้วทำต่อได้) |

4. ในโปรแกรม: วางคำตอบ + ลิงก์แหล่งที่มา แล้วพิมพ์ `END` บรรทัดใหม่
   - `SKIP` = ข้ามข้อนี้ (ไม่บันทึก) — ใช้เมื่อพลาด เช่น พิมพ์คำถามผิด แล้วเก็บใหม่ภายหลังด้วย `--queries`
   - `BLOCKED <หมายเหตุ>` = เจอหน้า login/CAPTCHA → บันทึกเป็น error แล้วหยุด session (ดูข้อ 5)
   - บรรทัดที่เป็นลิงก์จะถูกเก็บเป็น citation รองรับ `https://...`, `[1] https://...`, `[1]: https://...`,
     `1. https://...`, `- https://...` ข้อความหลัง URL ในบรรทัดเดียวกันจะเก็บเป็นชื่อ (title)

ไฟล์ที่ได้: `data/raw/<วันที่>_<provider>_app_manual.jsonl` (ห้าม commit โฟลเดอร์ `data/`)

## 2. General rules (all engines) / กติกาทุก engine

- **หน้าต่างใหม่แบบ private/incognito ทุก session** ปิดแล้วเปิดใหม่ระหว่าง engine
- **ไม่ login ถ้า engine ให้ใช้ได้โดยไม่ login** ถ้าจำเป็นต้อง login ให้ใช้บัญชีสำหรับงานวิจัยเท่านั้น
  (ไม่มีประวัติส่วนตัว ปิด memory/personalization) และจดใน `--note` ว่า `logged-in (research account)`
- **อยู่ในประเทศไทย ไม่ใช้ VPN/proxy** ใช้เครือข่ายเดิมทุกครั้งเท่าที่ทำได้ จดเมือง/เครือข่ายใน `--note`
- **ไม่เปลี่ยน model / mode / การตั้งค่า** ใช้ค่าเริ่มต้นที่หน้าเว็บให้มา ถ้าหน้าเว็บแสดงชื่อ model ให้จดใน `--note`
- **1 คำถาม = 1 แชตใหม่** ห้ามถามต่อในแชตเดิม (คำตอบก่อนหน้าจะมีผลกับคำตอบถัดไป)
- **พิมพ์/วางคำถามตรงตาม checklist ทุกตัวอักษร** (copy จาก checklist ดีที่สุด) ไม่เติมคำ ไม่แก้คำสะกด
- **ไม่ตอบคำถามที่ engine ถามกลับ** ถ้า engine ถามกลับ ("ต้องการงบเท่าไหร่?") ให้เก็บคำตอบนั้นตามที่เห็น
- **รอให้คำตอบขึ้นครบ** (ไม่มีจุดกระพริบ/ปุ่ม stop) ก่อนคัดลอก ไม่กด regenerate ไม่ให้คะแนน 👍/👎
- **คัดลอกทั้งคำตอบ** ด้วยปุ่ม Copy ของ engine (ถ้ามี) ไม่ตัดส่วนใด ๆ ทิ้ง
- **คัดลอกแหล่งที่มาทุกอัน** (ดูวิธีของแต่ละ engine ด้านล่าง) วางต่อท้ายคำตอบ บรรทัดละ 1 ลิงก์
  ปุ่ม Copy ส่วนใหญ่ **ไม่รวม** ลิงก์ทั้งหมด ต้องกางรายการ sources แล้วคัดลอกเอง (คลิกขวา → Copy link address)
- เว้นระยะระหว่างคำถามแบบคนใช้งานปกติ (ประมาณ 30–60 วินาที) ไม่รีบยิงต่อเนื่อง
- หน้าเว็บเปลี่ยน UI บ่อย ถ้าปุ่มไม่ตรงกับที่เขียนไว้ ให้ทำให้ได้ผลเดียวกัน แล้วจดสิ่งที่ต่างไว้ใน `--note`

## 3. Per-engine protocol / ขั้นตอนแยกตาม engine

### 3.1 Perplexity (web) — `--provider perplexity`

1. เปิดหน้าต่าง private ใหม่ → `https://www.perplexity.ai`
2. ไม่ login (ปิด popup ชวนสมัครด้วยปุ่ม ✕ ได้ ห้ามกรอกอะไร) ไม่เลือก model/Focus/Pro ใช้ค่าเริ่มต้น
3. วางคำถาม → Enter → รอคำตอบเสร็จ
4. คัดลอกคำตอบด้วยปุ่ม **Copy** ใต้คำตอบ → วางใน terminal
5. เปิดแท็บ/ปุ่ม **Sources** (หรือ "+N sources") เพื่อดูรายการทั้งหมด → คัดลอกลิงก์ **ทุกอัน** ตามลำดับเลข
   วางเป็น `[1] https://...`, `[2] https://...`
6. พิมพ์ `END` → กลับหน้าแรก (New Thread) สำหรับคำถามถัดไป

### 3.2 ChatGPT (web) — `--provider chatgpt`

1. เปิดหน้าต่าง private ใหม่ → `https://chatgpt.com`
2. ใช้แบบไม่ login ถ้าทำได้ ("Stay logged out") ไม่เปิด/ปิดปุ่ม Search เอง ใช้ค่าเริ่มต้น จดใน `--note` ว่าใช้แบบไหน
3. วางคำถาม → Enter → รอคำตอบเสร็จ
4. คัดลอกคำตอบด้วยปุ่ม **Copy** ใต้คำตอบ → วางใน terminal
5. ถ้าคำตอบมีแหล่งที่มา: กดปุ่ม **Sources** ท้ายคำตอบ จะเปิดแผงด้านข้าง → คัดลอกลิงก์ทุกอันในแผง
   (รวมส่วน "More"/รายการที่พับไว้) และลิงก์ชิป citation ในเนื้อหาที่ไม่อยู่ในแผง
6. ถ้าไม่มีแหล่งที่มาเลย ก็พิมพ์ `END` ได้เลย (ข้อมูลนี้มีค่า — แปลว่าตอบจากความรู้ของ model)
7. เริ่ม **New chat** สำหรับคำถามถัดไป

### 3.3 Gemini (web) — `--provider gemini`

1. เปิดหน้าต่าง private ใหม่ → `https://gemini.google.com`
2. ถ้าใช้ได้โดยไม่ login ให้ใช้แบบนั้น ถ้าบังคับ login ให้ใช้บัญชีวิจัยเท่านั้น (ปิด Gemini Apps Activity/personalization)
   และจดใน `--note` ห้ามใช้บัญชีส่วนตัว ไม่เปลี่ยน model ใน dropdown
3. วางคำถาม → Enter → รอคำตอบเสร็จ
4. คัดลอกคำตอบด้วยปุ่ม **Copy** (ไอคอนใต้คำตอบหรือในเมนู ⋮) → วางใน terminal
5. แหล่งที่มา: กด **Sources / Show sources** หรือชิปลิงก์ในเนื้อหา → คัดลอกลิงก์ทุกอัน
   **ห้ามกด "Double-check response"** (เพิ่มการค้นหาที่ผู้ใช้ทั่วไปไม่เห็น)
6. เริ่ม **New chat** สำหรับคำถามถัดไป

### 3.4 Google AI Mode — `--provider aimode`

1. เปิดหน้าต่าง private ใหม่ → `https://www.google.com` (ภาษาตามค่าเริ่มต้น ไม่เปลี่ยนเป็น google.com/ncr)
2. เลื่อนลงล่างสุดของหน้า ตรวจว่าตำแหน่งแสดงเป็น **ประเทศไทย** ถ้าไม่ใช่ให้จดใน `--note`
3. กดแท็บ/ปุ่ม **AI Mode** (หรือเข้า `https://www.google.com/aimode`) ถ้า AI Mode ไม่มีให้ใช้แบบไม่ login
   ให้หยุด จด `BLOCKED unavailable` ไม่ต้อง login บัญชีส่วนตัว
4. วางคำถาม → Enter → รอคำตอบเสร็จ
5. คัดลอกข้อความคำตอบ (ลากคลุมทั้งคำตอบ หรือใช้ปุ่ม Copy/Share ถ้ามี) → วางใน terminal
6. แหล่งที่มา: กดไอคอนลิงก์ 🔗 ในเนื้อหา และ **Show all** ในแผงแหล่งที่มาด้านข้าง → คัดลอกลิงก์ทุกอัน
   (ถ้าเป็นลิงก์ `google.com/url?...` ให้วางตามนั้น ไม่ต้องแก้)
7. เปิด AI Mode ใหม่ (New / ล้างแชต) สำหรับคำถามถัดไป

## 4. Timing rules / ช่วงเวลาที่เก็บ

- **1 รอบ (repeat) = ทุก query ใน checklist ของ engine นั้น** เก็บให้จบในวันเดียว
- **กระจายรอบข้ามวัน:** repeat 0 = วันที่ 1, repeat 1 = อย่างน้อย 2 วันถัดไป, repeat 2 = อย่างน้อย 2 วันถัดจากนั้น
  (ห้ามเก็บ repeat 2 รอบของ engine เดียวกันในวันเดียวกัน)
- **ช่วงเวลาเดียวกันของวัน** ทุกรอบ (เช่น 18:00–21:00) เพื่อลดผลจากเวลา
- **สูงสุด 2 session ต่อคนต่อวัน** (1 session = 1 engine × 1 repeat) และพักอย่างน้อย 30 นาทีระหว่าง session
- **ไม่เก็บ engine เดียวกันพร้อมกัน 2 คน จากเครือข่ายเดียวกัน**
- **แบ่งงานผู้เก็บ:** แต่ละ engine × repeat ให้คนเดียวเก็บจนจบ แนะนำสลับคนในรอบถัดไป
  เช่น repeat 0: A = Perplexity + AI Mode, B = ChatGPT + Gemini; repeat 1 สลับกัน
  (จะได้ดูได้ว่าผู้เก็บมีผลกับข้อมูลไหม)
- เก็บ Gemini API อัตโนมัติ (`python -m aiso.collect --provider gemini --no-search`) ในวันเดียวกับรอบ manual
  เพื่อให้เทียบกันได้

## 5. Login wall / CAPTCHA / ถูกบล็อก

1. **หยุดทันที** ห้ามกด "I'm not a robot", ห้ามแก้ CAPTCHA, ห้ามเปลี่ยน IP/VPN/เบราว์เซอร์เพื่อเลี่ยง, ห้ามสมัครบัญชีใหม่เพื่อเลี่ยง
2. ใน terminal พิมพ์ `BLOCKED <สิ่งที่เห็น>` เช่น `BLOCKED captcha after Q7` — โปรแกรมจะบันทึก error และหยุด
3. ติ๊ก **blocked** ใน checklist และจดเวลา
4. ปิดหน้าต่าง พักอย่างน้อยถึงวันถัดไป แล้วเก็บข้อที่เหลือด้วย `--queries` (เลขรอบเดิม)
5. ถ้าเจอซ้ำ 2 ครั้งติดกันใน engine เดียว ให้แจ้งทีม — อาจต้องตัด engine นั้นออก และเขียนเป็นข้อจำกัดในรายงาน
